# Mi Proyecto Python

Este repositorio contiene diferentes scripts en Python, creados para practicar lógica, automatización y el uso de librerías.  
Incluye ejemplos simples y algunos proyectos pequeños que pueden servir como base para desarrollos futuros.

## 📂 Contenido del repositorio

- `/scripts/` → scripts pequeños en Python  
- `/utils/` → funciones auxiliares  
- `main.py` → punto de inicio para ejecutar pruebas  
- `requirements.txt` → dependencias del proyecto
